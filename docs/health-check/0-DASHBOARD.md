## 三、Top 5 关键问题

### 1. [严重] _testOpenid 身份伪造后门

- **来源**: 7-security-vulnerabilities.md (V-02)
- **影响**: 所有 4 个云函数均可被客户端伪造身份，冒充任意用户执行操作
- **状态**: 已识别，未修复
- **修复难度**: 低（移除或加环境变量判断）

### 2. [严重] 依赖存在高危 CVE 漏洞

- **来源**: 2-dependency-audit.md
- **影响**: python-multipart 0.0.6 (CVE-2024-24762 ReDoS)、numpy 1.24.0 (CVE-2023-33953 缓冲区溢出)
- **状态**: 未修复
- **修复难度**: 低（更新 requirements.txt 版本号）

### 3. [高] 所有云函数缺少顶层 try-catch

- **来源**: 5-error-handling.md
- **影响**: 4 个云函数入口 + 20+ 个内部函数无异常捕获，数据库异常直接暴露给客户端
- **状态**: 未修复
- **修复难度**: 低（每个文件加 1 个 try-catch 包裹）

### 4. [高] 零测试覆盖

- **来源**: 8-test-coverage.md
- **影响**: 24 个 JS 源文件、4 个云函数、10 个页面全部无测试，重构和迭代无安全网
- **状态**: 仅生成 3 个测试文件（23 个用例），未集成到项目
- **修复难度**: 中（需建立测试框架，逐步补充）

### 5. [中] 云函数代码严重重复

- **来源**: 3-code-duplication.md + 4-architecture-critique.md
- **影响**: 用户查询模式重复 10+ 次、SDK 初始化 4 处相同、God Object (todos 321 行)
- **状态**: 未修复
- **修复难度**: 中（需提取共享模块，重构路由）
